# gce_models
This repository contains the dark matter halo models used for the Galactic Center Gamma-ray Excess (GCE) analysis in [L. Q. Hu, I. Cholis, and Y.-M. Zhong, (2026)](https://inspirehep.net/literature/3123202)

# The Benchmarks
The benchmarks used [L. Q. Hu, I. Cholis, and Y.-M. Zhong, (2026)](https://inspirehep.net/literature/3123202) for 20x20 inner ROI and for the cuspiness parameter gamma=1.2.

``` spherical_front_only_14_Ebin_20x20window_normal.npy ``` - spherical dark matter halo. \
``` benchmark_1_front_only_14_Ebin_20x20window_normal.npy ``` - Benchmark 1, please see for [J. J. Han et al., Astron. J. 164, 249 (2022), 2208.04327.](https://arxiv.org/abs/2208.04327) for details. \
``` benchmark_2_front_only_14_Ebin_20x20window_normal.npy ``` - Benchmark 2, please see [J. Nibauer and A. Bonaca, Astrophys. J. Lett. 985, L22 (2025), 2504.07187](https://arxiv.org/abs/2504.07187) for details. \
``` flipped_benchmark_1_front_only_14_Ebin_20x20window_normal.npy ``` - The flipped benchmark 1. The yaw angle rotation is flipped \
